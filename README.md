## 📌 สูตรการคำนวณใน Google Sheet (ชีท `คะแนน`)

### 1. สูตรใน Cell N2 (`I N คำนวณ` / $I_{nc}$)
ปัจจุบันในชีทมีสูตรคำนวณกระแสนิวทรัลทางทฤษฎี ($I_{nc}$) อยู่แล้ว:
```excel
=BYROW(J2:L30, LAMBDA(r, IF(INDEX(r, 1)="", "", LET(e, INDEX(r, 1), f, INDEX(r, 2), g, INDEX(r, 3), SQRT(MAX(e^2 + f^2 + g^2 - (e*f + f*g + g*e), 0))))))
```

### 2. สูตรใน Cell O2 (`kW คำนวณจากวัดจริง`)
*ให้ลบสูตรใน Cell O14 ออก (ซึ่งเป็นสูตรหาค่าเฉลี่ย AVERAGE ที่หลงอยู่)* แล้วนำสูตรนี้ไปวางใน **Cell O2**:
```excel
=BYROW(J2:L30, LAMBDA(r, IF(INDEX(r, 1)="", "", ROUND((INDEX(r, 1) + INDEX(r, 2) + INDEX(r, 3)) * 0.23 * 0.9, 2))))
```
หรือรูปแบบ ARRAYFORMULA:
```excel
=ARRAYFORMULA(IF(B2:B30="", "", IF(J2:J30="", "", ROUND((J2:J30 + K2:K30 + L2:L30) * 0.23 * 0.9, 2))))
```

### การทำงานของสูตร:
- นำผลรวมกระแสจริง $I_a$ (Col J) + $I_b$ (Col K) + $I_c$ (Col L) มาคูณ $0.23 \text{ kV} \times 0.9$ (Power Factor)
- ป้อนค่า $kW$ วัดจริงเข้าสู่ Col T เพื่อคำนวณ $\%Load = (kW / kVA) \times 100$ ได้อย่างถูกต้อง
- **แอปพลิเคชันจะไม่แตะต้องหรือเขียนทับ Col N และ Col O** จึงรักษาการทำงานของสูตรไว้อย่างปลอดภัย 100%

## 📱 โครงสร้างหน้าจอหลัก 3 แท็บ (Mobile-First Experience)

1. **🗺️ แผนที่ชี้เป้าลงตรวจ (Default Landing Tab):**
   - **บน Mobile:** ซ่อนลิสต์ยาวๆ เปลี่ยนเป็น **Dropdown เลือกหม้อแปลง** เหนือแผนที่ เมื่อเลือกแล้วแผนที่จะบินไปซูมที่หม้อแปลงลูกนั้นทันทีพร้อมเปิด Popup และปรับความสูงแผนที่ให้พอดีหน้าจอมือถือ (100dvh) โดยไม่ต้องเลื่อนจอ
   - **บน Desktop:** แสดงแผนที่ด้านซ้าย และ Sidebar รายชื่อหม้อแปลงด้านขวาตามเดิม
   - ใน Popup ทุกจุดมีปุ่ม **"🧭 นำทาง Google Maps"** และปุ่ม **"📝 บันทึกข้อมูลตรวจเช็ค"**

2. **📝 บันทึกผลตรวจเช็คหน้างาน:**
   - **Step 1:** ตรวจวัดตู้หม้อแปลงแยกฟีดเดอร์ Default เริ่มต้นที่ **1 Feeder** พร้อม Dropdown เลือก Feeder 1 ถึง Feeder 6 (ไม่มีคำว่า ซ้าย/ขวา)
   - **Step 2:** บันทึกการเดินไล่วัดตาม Line เป็น **การ์ดจุดวัดตามเสาแนวตั้ง (Stacked Cards)** พอดีหน้าจอมือถือ ไม่ต้องเลื่อนจอซ้ายขวา พร้อมระบบคำนวณ $I_{avg}, I_{nc}, E$ และแจ้งเตือนเมื่อพบกระแส $I_n$ ดรอปลงจากเสาก่อนหน้า
   - **Step 3:** รวมกระแสทั้งหม้อแปลงอัตโนมัติ ($I_{a, sum}, I_{b, sum}, I_{c, sum}, I_{n, sum}, kW$), ระบุรหัสพนักงาน (บังคับตัวเลข), กรอกหมายเหตุ, ถ่ายรูปหลักฐาน พร้อมปุ่มส่งผลเดียว **"☁️ บันทึกผลเข้า Google Sheet"**

3. **📋 รายการหม้อแปลงที่ต้องตรวจสอบ:**
   - ตารางเปรียบเทียบผลตรวจ Before (Col G) vs After (Col AF)
   - สรุปตัวเลขผลการชี้เป้า (True Positive vs False Positive)
   - จุดตั้งค่า Web App URL สำหรับการซิงค์ข้อมูลออนไลน์

1. เปิด Google Sheet: **ID `1MAl3n2rzX4U1foeEZeRyklbutylYb0X3CJO2pH0bzNE`**
2. ไปที่เมนู **ส่วนขยาย (Extensions)** $\rightarrow$ **Apps Script**

5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** $\rightarrow$ **การทำให้ใช้งานได้ใหม่ (New deployment)**:
   - ชนิด: **เว็บแอป (Web app)**
   - คำอธิบาย: TR Inspection & Feeder API v2
   - ทำงานในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป (Web app URL)**
7. นำ Web app URL ไปวางในช่องตั้งค่าในแท็บ **"📋 รายการหม้อแปลงที่ต้องตรวจสอบ"** ในแอป `index.html`
